I build backend services for a fintech payment and compliance platform — **Java/Spring Boot** on the server, **Oracle SQL** underneath, **Flutter** and **React** at the edges.

Before that I spent my MSc on **US2UCD**: an NLP pipeline (Stanza, CoreNLP) that generates UML use case diagrams straight from natural-language user stories. Three publications, sixteen citations, and a permanent habit of over-formalizing things that did not need formalizing.

The rest of the time I build small SaaS products end to end, mostly to find out whether I can.

## Research

</div>

> **US2UCD** — *Automated generation of UML use case diagrams from natural-language user stories.*
>
> A rule-and-dependency pipeline over Stanza and Stanford CoreNLP that extracts actors, use cases, and relationships from plain-English user stories, then emits a valid use case diagram. Evaluated across sixteen case studies against human-drawn baselines.
